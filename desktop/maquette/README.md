# Maquettes de l'application PC

Ces prototypes explorent l'interface desktop. L'application maintenue est décrite dans le [README parent](../README.md).

Depuis ce dossier, `python -m http.server 8000 --bind 127.0.0.1` sert les fichiers. Ouvrir ensuite `http://127.0.0.1:8000/fenetre-pc.html`, `mini-pc.html` ou `session-complete-prototype.html`. Les fichiers de `figma-pc/` sont des maquettes SVG et HTML ; `figma-pc/build_mockups.py` les régénère localement.

Les tests de `pose-engine.test.mjs` sont inclus dans `task test:desktop` depuis la racine du dépôt, ou `npm test` depuis `desktop/`.
