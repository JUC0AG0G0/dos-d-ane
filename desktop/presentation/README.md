# Présentation desktop

`Dos-d-ane-recherche.pptx` et le dossier `images/` conservent le support de recherche de l'application PC. Ces documents historiques ne sont pas embarqués dans l'installateur.

Les protocoles de benchmark sont documentés dans [benchmark-README.txt](../benchmark-README.txt) et [full-benchmark-README.txt](../full-benchmark-README.txt). Les nouvelles mesures et archives sont générées sous `desktop/output/`, hors Git.
